# CLEAR

CLEAR è un progetto di ricerca sviluppato dall'azienda Net Service, in collaborazione con l'azienda Flosslab, a cui ho preso parte durante la mia attività di tirocinio (540 ore) e durante un ulteriore periodo prolungato dalla durata di 4 mesi. Lo scopo del progetto è quello di creare un modello di IA utilizzato per analizzare e classificare il traffico dati in normale o anomalo. La repository contiene il lavoro che ho svolto, partendo dallo script in lua utilizzato da Fluent Bit per estrarre le feature dal dataset in modo da arricchirlo, proseguendo con l'algoritmo di Autoencoder, il quale è risultato essere il più affidabile, ed infine lo script basato su Autoencoder per addestrare il modello tramite Federated Learning. Per una spiegazione più dettagliata del lavoro, basti consultare il file pdf riguardante la mia tesi di laurea magistrale, all'interno del quale viene approfondito lo studio teorico e sperimentale alla base del progetto CLEAR.
